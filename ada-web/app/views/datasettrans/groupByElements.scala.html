@import org.edena.ada.server.models.datatrans.GroupByTransformation @import views.html.datasettrans.dataSetTypeahead @import views.html.elements.{inputText, textarea} @import org.edena.play.controllers.WebContext @import org.edena.play.controllers.WebContext._ @import reactivemongo.api.bson.BSONObjectID @( id: Option[BSONObjectID], form: Form[GroupByTransformation] )( implicit webContext: WebContext ) @dataSetTypeahead("groupByTransformation", "sourceDataSetId", form, id, Some("Grouped"))

Aggregates the rows with the same values of the group-by fields to one row of a new data set (e.g. examinations to patients): the group-by values and the aggregated values, whose fields are derived from the aggregations. The rows of a group are ordered by the order fields (an undefined value last), which defines first / last and the order of collected values.

@inputText("groupByTransformation", "groupByFieldNames", form) @textarea("groupByTransformation", "orderBy", form, Seq('rows -> 4)) @textarea("groupByTransformation", "aggregations", form, Seq('rows -> 20))

An aggregation: outFieldName, function, inFieldNames (several for CountDistinct, Mode, Collect, CollectDistinct, Priority; none for Count), optionally label, categoryName (created if missing), conditions (filter conditions: only the matching rows are aggregated; on an array field = means an element equals), excludeValues, skipNulls (First / Last), ranking (Priority), distinctFieldName (Mode: a value counted once per distinct value of this field).

Functions: Count, CountDistinct (Integer), Min, Max, First, Last, Mode (the most frequent value, the first on a tie), Collect (an array of all the values, repeated ones too; undefined ones skipped), CollectDistinct (an array of the distinct values), Priority (the highest-ranked value present), Sum, Avg (Double). An array field's values are its elements (First / Last take the whole array).
