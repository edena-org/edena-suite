Filter defines a data/cohort selection and is specified as a sequence of conditions connected by AND operator. Supported condition types are:

  • =
  • !=
  • <
  • >
  • <=
  • >=
  • like
  • in
  • nin
  • contains - all the given words occur (in any order, case-insensitive); for Text fields stored in Elasticsearch whole words are matched (full-text search), otherwise substrings
  • is defined / is undefined - whether the field has a value
Text fields support contains, is defined, and is undefined. Exact equality, inequality, ranges, and regular-expression filters are not supported for Text. For other fields, an empty comparison value is treated as null (or undefined). Filters can be saved and applied across the platform for views, analytics (e.g., scatters), and machine learning (e.g., classification, and clusterization).
